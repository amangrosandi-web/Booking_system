# 📅 Booking System - Divisi Layanan Darurat ITB

Sistem pemesanan (booking) berbasis web untuk mempermudah koordinasi dan manajemen layanan di lingkungan Divisi Layanan Darurat ITB.

## 🚀 Update Fitur Terbaru
Saya baru saja memperbarui sistem ini dengan beberapa peningkatan fitur utama:
*   **Form Pemesanan Interaktif**: Pengguna sekarang dapat mengisi data reservasi dengan lebih mudah.
*   **Validasi Input**: Memastikan semua data terisi dengan benar sebelum dikirim ke sistem.
*   **Optimasi Tampilan (Responsive)**: Antarmuka yang lebih rapi dan nyaman dibuka melalui perangkat mobile maupun desktop.
*   **Integrasi GitHub Pages**: Sistem sudah dapat diakses langsung secara online.

## 🛠️ Teknologi yang Digunakan
*   **HTML5**: Struktur utama halaman web.
*   **CSS3**: Styling dan tata letak antarmuka.
*   **JavaScript**: Logika fungsional untuk sistem booking.
*   **GitHub Pages**: Hosting untuk deployment website.

## 📖 Cara Penggunaan
1. Akses website melalui link GitHub Pages yang tersedia.
2. Pilih layanan atau jadwal yang diinginkan pada form yang tersedia.
3. Isi detail informasi yang diperlukan.
4. Klik tombol **Submit** atau **Book Now** untuk mengirim data.
